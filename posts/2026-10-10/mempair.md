---
title: Mempair - Memory pair web game
---


I like [Memory](https://play.google.com/store/apps/details?id=com.ravensburger.memory&hl=en-US) game implementation, but not the menu system,
nor that it is pretty slow in most aspects. So I decided to see if an LLM could create a "better" variant of the same game, with using my
[Yukon](https://github.com/gmelchett/yukon) card web game as base. And yes, after some time with LLMs and like half a dollar in cost,
I'm pretty happy with the result. Most time was spend browsing for suitable card images. There are some that are not that good and I'll
probably replace in later version. We'll see.
Anyway, here is the [source](https://github.com/gmelchett/mempair) and playable version of [Mempair](https://gmelchett.github.io/2026-10-10/mempair/index.html).
As with Yukon, it can be installed as a PWA, which I recommend to get rid of the browser menus.
