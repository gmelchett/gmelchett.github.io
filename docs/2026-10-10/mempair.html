Mempair - Memory pair web game

Saturday, 10th October 2026

I like Memory game implementation, but not the menu system, nor that it is pretty slow in most aspects. So I decided to see if an LLM could create a “better” variant of the same game, with using my Yukon card web game as base. And yes, after some time with LLMs and like half a dollar in cost, I’m pretty happy with the result. Most time was spend browsing for suitable card images. There are some that are not that good and I’ll probably replace in later version. We’ll see. Anyway, here is the source and playable version of Mempair. As with Yukon, it can be installed as a PWA, which I recommend to get rid of the browser menus.
